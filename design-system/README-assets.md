# AvangardAI design-system — canonical full-res source

Полноразмерный источник фирменного стиля AvangardAI: оригинальные текстуры
«хаос-куба» (PNG в полном разрешении), логотипы, аватар CEO, скрин продукта,
шрифты (Golos Text, Geist Mono), токены `colors_and_type.css`, `preview/`-карточки
и `ui_kits/`.

Рантайм-слайс живёт в приватном `the-most-ai/most-skills` → плагин `design`
(скилл `avangardai-design`), где текстуры ужаты в JPEG ради веса. Сюда ходят,
когда нужен хиро-рес оригинал, а не упакованная JPEG-версия.

Raw-ссылка на файл:
`https://raw.githubusercontent.com/the-most-ai/assets/main/design-system/<path>`
